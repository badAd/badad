# How to use

## For writeto...php
1. `vim keygen.php` - make sure the email is the same as the admin
2. `php -f keygen.php`
3. `vim writeto_FILE_.php` - make sure the message is correct
4. `head writeto_FILE_.php`
5. Copy `writeto_FILE_.php` to the webdir, then go to the address with the key, as indicated
6. Delete `writeto_FILE_.php` from the webdir

## For tallies
1. `vim tallykeygen.php` - make sure the email is the same as the admin
2. `php -f tallykeygen.php`
3. `head partnersitehitcalculation.php`
4. Copy `partnersitehitcalculation.php` to the webdir, then go to the address with the key, as indicated
5. Delete `partnersitehitcalculation.php` from the webdir

## Cat IDs
1. Copy `updatecatids.php` to the webdir
2. Go to that URL
3. Delete `updatecatids.php` from the webdir
